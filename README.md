# Скрипт для скачивания ресурсов курса Moodle

> 🤖 **Примечание:** Данный скрипт был **полностью создан искусственным интеллектом (ИИ)** для автоматизации пакетного скачивания файлов, материалов и папок со страницы курса Moodle.

---

## 📌 Описание

Автономный JavaScript-скрипт для браузера, который находит все прикрепленные ресурсы и папки с файлами на странице курса Moodle, загружает их с сохранением авторизации и упаковывает в единый структурированный `.zip`-архив без сторонних библиотек.

---

## 🚀 Инструкция по использованию

1. Откройте нужную страницу курса в **Moodle** в вашем браузере (убедитесь, что вы авторизованы в системе).
2. Откройте **Консоль разработчика** (Developer Tools):
   - Нажмите <kbd>F12</kbd> (или <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>I</kbd> / на macOS: <kbd>Cmd</kbd> + <kbd>Option</kbd> + <kbd>I</kbd>).
   - Перейдите на вкладку **Console** (Консоль).
3. Скопируйте всё содержимое файла [`parse_resourses.js`](./parse_resourses.js).
4. Вставьте код в консоль и нажмите <kbd>Enter</kbd>.
5. Дождитесь завершения работы скрипта: в консоли будет выводиться лог загрузки ресурсов и статус формирования архива, после чего автоматически начнется скачивание готового `.zip`-файла.

---

## ⚙️ Возможности и особенности работы

- **Автономность (Zero Dependencies):** Скрипт не требует установки расширений или подключения внешних библиотек (JSZip и др.). Сборка ZIP-структуры (Local File Headers, Central Directory, контрольные суммы CRC32) реализована нативно с помощью `Uint8Array` и `Blob`.
- **Поддержка отдельных файлов и папок (Folders):**
  - **Обычные ресурсы (`modtype_resource`):** скачиваются напрямую.
  - **Папки Moodle (`modtype_folder`):** скрипт открывает страницы папок в фоне, извлекает вложенные файлы и сохраняет их в соответствующие поддиректории внутри архива.
- **Умное определение расширений файлов:** Скрипт определяет расширение файла по цепочке:
  1. Из заголовка `Content-Disposition` (включая кодировку UTF-8 / RFC 5987);
  2. По MIME-типу из заголовка `Content-Type` (PDF, DOC/DOCX, PPT/PPTX, XLS/XLSX, архивы, изображения, медиа);
  3. Из пути в URL-адресе.
- **Сохранение сессии:** Запросы выполняются через `fetch` с параметром `credentials: "include"`, благодаря чему сохраняются все активные сессионные cookies.
- **Разрешение конфликтов имен:** При совпадении названий файлов или путей автоматически добавляется числовой индекс (например, `Имя файла (1).pdf`).
- **Информативное имя архива:** Архив автоматически именуется по шаблону с датой, временем и названием курса:  
  `ДД.ММ.ГГГГ ЧЧ:ММ - <Название курса>.zip`.
- **Индикация процесса:** Подробный прогресс по каждому ресурсу и процент сборки архива выводятся в консоль, а по завершении выводится всплывающее уведомление (`alert`)..
